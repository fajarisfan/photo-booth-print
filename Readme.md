# 📸 Photo Booth Print

Aplikasi cetak foto berbasis Streamlit — foto via webcam atau upload,
pilih template layout, download PDF/JPG siap cetak 300 DPI.

#Fitur
- 📷 Webcam capture & file upload
- 7 template: Pas Foto 2x3/3x4/4x6, Polaroid Strip, Photo Booth Grid, Film Strip, Wallet Print
- Output PDF + JPG 300 DPI (A4 ready)
- Download semua template sekaligus (ZIP)

# jalankan
pip install -r requirements.txt
streamlit run app.py
